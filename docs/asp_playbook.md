# 国内ASP登録ガイド(シニアペット用品ニッチ向け)

## 紹介料率の前提(Amazon.co.jp、2026年時点)

| 料率 | カテゴリー |
|---|---|
| 8% | 服&ファッション小物、ジュエリー、シューズ&バッグ |
| 5% | ドラッグストア、ビューティー・コスメ、**ペット用品** |
| 4% | ベビー&マタニティ、スポーツ用品 |
| 2% | 家電全般(キッチン家電・生活家電・理美容家電含む) |

ペット用品は5%と比較的良い料率帯。当初はA8.net/もしもアフィリエイトの個別ペット保険案件(固定報酬型)を組み合わせる想定だったが、2026-07-28時点で実際に確認したところ、A8.net・もしもアフィリエイトいずれにも提携可能なペット保険案件は見つからなかった(下記2・3参照)。現状はAmazon.co.jp中心の物販構成で運用する。

## 登録の優先順位

1. **Amazon.co.jp アソシエイト**(物販の基本、まず登録)
2. **A8.net**(案件数最大、承認されやすい)
3. **もしもアフィリエイト**(Amazon/楽天のW報酬12%上乗せがすぐ使える)
4. **afb**(実績が出てから単価交渉できるタイプなので後回しでOK)

---

## 1. Amazon.co.jp アソシエイト

- 申請先: https://affiliate.amazon.co.jp
- 米国版(affiliate-program.amazon.com)とは別登録。既存のUS用Amazonアソシエイトとは紐付かない
- 必要なもの: サイトURL(GitHub Pagesで公開後のURL)
- ペット用品カテゴリの紹介料率は5%

## 2. A8.net

- 申請先: https://www.a8.net
- 国内最大手、登録サイト数約340万、案件数約5,500件
- ペット関連: ペットフード、消臭ケア、サプリなど。**2026-07-28時点で確認した限り、提携可能なペット保険(代理店)案件は無し**。保険記事を書く場合はAmazon.co.jpのサプリ・グッズ紹介に絞る
- 審査は比較的通りやすいが、サイトに実際のコンテンツ(今回の3記事等)があることが前提

## 3. もしもアフィリエイト

- 申請先: https://af.moshimo.com
- 特徴: **W報酬制度**(通常報酬に12%上乗せ)。Amazon・楽天との提携がしやすい設計
- Amazonリンクを扱う際は、もしもアフィリエイトの「らくらくリンク」経由にすることで、直接のAmazonアソシエイトより実質的な報酬が増える可能性がある(具体的な組み込み方は登録後にツールの案内に従うこと)
- ペット関連: ペットフード、シャンプー、ペット用品全般。**2026-07-28時点で確認した限り、提携可能なペット保険案件は無し**

## 4. afb

- 申請先: https://www.afi-b.com
- 管理画面が使いやすく、支払いサイクルが翌月末と早い
- 実績が出た後に個別単価交渉ができるタイプなので、サイトが育ってから登録するのが効率的
- ペット関連: ペットフード、消臭ケア、水、サプリ、保険など

---

## 運用上の注意

- Amazon・A8.net・もしもアフィリエイトいずれも、リンクには広告であることが分かる表記(`affiliate-disclosure`ページへの導線)を必ず設置する
- ペット保険・保険代理店系の案件は、補償内容を断定的に説明しない(「多くの場合」「一般的には」の言い回しを使い、最終確認は必ず公式資料に委ねる書き方にする)
- 各ASPの規約・紹介料率は変更されることがあるため、登録前に必ず最新情報を確認する
