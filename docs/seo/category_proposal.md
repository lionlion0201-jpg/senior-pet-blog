# テーマ(カテゴリ)分けの提案 — シニアペットのくらし

ブランチ `seo/clusters`。如月さんの承認待ち。

## 目的
- 記事末尾の関連記事が全記事(44本)へのリンクになっていて、どの記事がどのテーマに属するかが Google に伝わらない。
- テーマ別のまとめページ(/category/<スラッグ>/)を作り、関連記事を同じテーマの記事(最大6本)に絞る。

## 仕組み(記事ファイルは書き換えない)
- テーマの定義と「記事スラッグ → テーマ」の対応は `src/_data/categories.json` に置く。
- **新しい記事を作ったら、`categories.json` の `posts` に `"記事スラッグ": "テーマのスラッグ"` を1行足す。**
  足し忘れても止まらない:その記事はどのまとめページにも出ず、パンくずは「ホーム > 記事」、関連記事は新しい順の記事4本になる。ビルド時に `[categories] テーマ未登録の公開記事があります` と警告が出る。
- まとめページ・関連記事には公開済みの記事だけが出る(予約公開は公開日の再ビルドで自動的に加わる)。公開中が0本のテーマはページを作らない。
- 関連記事:同じテーマの公開記事を新しい順に最大6本。同テーマが4本未満なら、ほかのテーマの新しい記事で4本まで補う。

## 決めてほしいこと
1. テーマは8つ(依頼の目安4〜7より1つ多い)。各テーマに公開中4本以上を確保しつつ、読者の悩みの単位を崩さない分け方にした結果。7つにするなら「体調管理・保険・買い方」を解体し、体調記録・投薬・採尿を「体のケア」へ、保険・セールは「テーマなし」にする案がある(その場合、保険・セールの記事はどのまとめページにも出ない)。
2. 下の表の「迷った理由」がある記事の振り分け。
