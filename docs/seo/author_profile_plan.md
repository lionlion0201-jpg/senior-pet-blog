# 運営者プロフィール(E-E-A-T)構成案と質問案 — シニアペットのくらし

作成: 2026-10-17。この文書は構成案と質問リストだけで、プロフィール本文は含まない。本文は如月さんの実体験の回答をもとに作る(事実を創作しない)。

## (a) 現状の不足点

現在の運営者情報ページ(`src/about/index.md`)は約5行。書いてあるのは「実用性重視で比較・紹介」「執筆の一部にAIを活用」「公開前に運営者が内容確認」のみ。

| # | 不足 | 影響 |
|---|---|---|
| 1 | 誰が運営しているかが無い(名前・ハンドル名・屋号のどれも無い。サイト上の著者は「シニアペットのくらし編集部」) | 経験(Experience)・信頼性(Trust)が評価できない |
| 2 | 運営者とペットの関わり(飼育歴・介護経験)が無い | 老犬・老猫の介護という「経験が重く見られる」分野で、経験の根拠がゼロ |
| 3 | お問い合わせ先が運営者情報に無い。プライバシーポリシーは「運営者情報ページのお問い合わせ先まで」と案内しているが、運営者情報に書かれていない(案内が行き止まり) | 信頼性の欠落。実害のある不整合なので最優先 |
| 4 | 記事の作り方の説明が1行のみ(AI下書き→運営者確認)。何を確認しているか、情報源、商品の選び方の基準が無い | 透明性不足 |
| 5 | 医療・獣医療情報の扱いが運営者情報に無い(個別記事には「治療の代わりにならない」旨の注意書きがある記事もある)。獣医師の監修は現状無い | 「専門家のサイト」と誤解させない線引きを、サイト全体の方針として明文化する必要 |
| 6 | 更新方針が無い(価格・仕様の変化への対応、誤りの訂正方法) | 鮮度・正確性の担保が見えない |
| 7 | 収益構造の説明が運営者情報に無い(広告表記ページはある) | 運営者情報からも広告表記へ誘導すると親切 |
| 8 | 記事末尾に著者表示が無い | 記事単位で誰が書いたか分からない |
| 9 | 記事の一人称の体験表現(「うちの犬が〜」)が12本にある。実体験に基づくなら強みだが、事実でないなら問題 | プロフィールで述べる経験と矛盾しないか要確認。事実でない記述は削除/書き換えを推奨(下記質問Q12) |
| 10 | 外部のプロフィール(X など)への導線が運営者情報に無い | 運営者の実在性の補強 |

## (b) 推奨する運営者情報ページの構成(見出し案)

1. このサイトについて(目的・誰の何を助けたいか。2〜3文)
2. 運営者(名前またはハンドル名、顔出しの有無は任意。一言の肩書きは事実のみ)
3. ペットとの関わり(飼育歴・介護経験。[実体験の回答から])
4. 記事の作り方(下書きの作り方、確認の手順、情報源。(e)参照)
5. 商品の選び方の基準(何を見て比較しているか。実際に使った物と、調べて紹介する物の区別)
6. 医療・獣医療情報の扱い(獣医師ではないこと、監修の有無、受診の目安は断定しない)
7. 更新と訂正の方針(更新日の表示、価格・在庫の変動、誤りの連絡先と対応)
8. 収益について(アフィリエイト広告を含むこと、広告表記ページへのリンク、推奨内容は報酬に左右されない方針を書けるなら)
9. お問い合わせ(連絡先。メールアドレス or フォーム。プライバシーポリシーの案内とつなぐ)
10. 外部リンク(X など。任意)

### 記事の作り方の説明案(誠実に書く場合の骨子。事実と違う部分は直す)

現状の運用(docs/agents/ より): マーケター(テーマ)→ アーキテクト(設計図)→ レビュワー(本文執筆。AI)→ ディレクター(公開可否チェック)→ 人間の週末レビュー → 公開。レビュワーの執筆ルールに「実際に使っていない商品を『使ってみた』と装う表現は使わない」「医療・保険は断定しない」がある。**JP には、US にあるファクトチェッカー工程(公式情報との照合)は現状無い**。次のように書く案:

- 「記事の下書きの作成にAIツールを使っています。公開前に運営者が内容を確認しています」(現状のまま。これは事実)
- 「商品は実際に使ったものと、公式情報・販売ページ・口コミを調べて紹介するものがあります。使ったものには『使用した』と明記します」(※この区別を記事側でも守れる場合のみ。守れないなら書かない)
- 「確認の手順」は、実際に行っていることだけを列挙する。行っていないこと(例: 公式情報との照合、獣医師の監修)は書かない。照合を始めるなら、その開始後の記事から書く
- 書かないこと: 「専門家が監修」「獣医師の知見」「徹底検証」「実際に試した」(根拠が無い限り)

## (c) 如月さんへの質問リスト(全部で16問)

すべて、答えたくなければ「無回答」で構いません。名前・顔・個人が特定される情報は出さない選択も可能です(その場合はハンドル名と「一人の飼い主として」という書き方に切り替える)。

**A. ペットとの経験(最重要。実体験が最も評価される部分)**
1. 今飼っている、またはこれまで飼っていたペット(犬/猫、種類、年齢、何年一緒だったか)。名前は伏せても可
2. シニア期のペットを介護した、または介護中の経験はあるか。ある場合、何歳ごろから、どんな変化があったか(足腰、食事、排泄、夜鳴き、認知機能 など)
3. 実際に使って役立った介護・生活用品(商品名またはカテゴリ)と、使ってみての感想(良かった点と不便だった点)
4. 買って失敗した物・使わなくなった物(任意。失敗談は信頼性を高めるが、無ければ無回答で可)
5. 獣医師に相談して決めたことはあるか(例: 歩行補助、食事の変更)。差し支えない範囲で
6. ペット保険に加入している/いた経験(任意。保険記事の信頼性に直結)

**B. 運営者について**
7. 表示したい名前(本名/ハンドル名/編集部のまま)と、顔出しの可否(任意)
8. 本業や経歴のうち、公開してよく、このテーマに関係するもの(任意。無関係なら不要。資格が無ければ書かない)
9. サイトを始めたきっかけ(一言で)
10. ペットや獣医療に関する資格・修了講座(ペットシッター、愛玩動物看護師 など)があれば。無ければ「無し」と回答(その場合、専門家とは書かない)

**C. 運営方針**
11. 公開してよい連絡先(メールアドレス or 問い合わせフォーム)。現在プライバシーポリシーが案内している「運営者情報のお問い合わせ先」を埋めるため必須に近い
12. 記事内の「うちの犬が〜」のような一人称表現(12本)は、実際の経験か。実際の経験でない場合、表現を「多くの飼い主さんは〜」などに直す
13. 商品は実際に購入・使用して記事を書いたものがあるか。ある場合、どの記事か
14. 獣医師に監修を依頼する予定・可能性はあるか(現状無いなら、無いと明記する方針で良いか)
15. 訂正があった場合の対応(連絡を受けたら確認して修正し、更新日を変える、で良いか)
16. 公開してよい外部アカウント(X など)

## (d) 記事末尾の著者紹介テンプレート(中身は空欄)

```
<aside class="author-box">
  この記事を書いた人: [名前/ハンドル名]
  [ペットとの関わりを1〜2文。例の型: ○○歳の[犬/猫]を[介護した/介護中]の飼い主 ← 事実だけ]
  [この記事のテーマに関する実体験があれば1文。無ければこの行は削除]
  医療に関する内容は一般的な情報で、診断・治療の代わりにはなりません。気になる症状は獣医師にご相談ください。
  [運営者情報へのリンク]
</aside>
```

注意: 実体験が無い記事には「実体験」の行を入れない。資格・監修者が無いなら肩書きは書かない。
