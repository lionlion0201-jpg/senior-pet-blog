# 保留中の下書き

季節外などの理由で、週末レビューに出さずに保管している下書き。`src/posts/` の外に置いているので、サイトにもレビュー画面にも出ない。

| ファイル | 保留の理由 | 戻す日(`holdUntil`) |
|---|---|---|
| `rougan-rouneko-necchusho-taisaku.md` | 熱中症(旬は6〜8月)。2026-10-10 に如月さんが来年5月ごろまで見送りと決定 | 2027-05-01 |

## 自動で戻る仕組み

- 各ファイルのフロントマターに `holdUntil: "YYYY-MM-DD"` を書いておく
- 毎週土曜の記事生成タスク(`jp-weekly-content-pipeline`)が最初に `python3 scripts/restore_held_drafts.py` を実行し、戻す日を過ぎた下書きを `src/posts/` に戻す(`holdUntil` の行は外れ、非公開の3行は残る)
- 戻った下書きはその週のレビュー画面に出る。リンク先の公開日や商品は、その回のディレクターチェックで見直す

保留を追加するときは、ファイルをここに移して `holdUntil` を書き、この表に1行足す。
